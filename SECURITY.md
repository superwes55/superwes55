# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in secretscope itself, please **do not** open a public issue.

Instead, open a [GitHub Security Advisory](https://github.com/superwes55/superwes55/security/advisories/new) or email the maintainer directly.

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce.
- Any suggested mitigations.

You can expect an acknowledgement within 72 hours and a resolution timeline within 14 days for critical issues.

## Responsible Use

secretscope is intended for **authorized security testing only**. Use of this tool against systems you do not own or have explicit written permission to test may violate computer-fraud laws in your jurisdiction. See [README.md](README.md) for the full responsible-use disclaimer.
